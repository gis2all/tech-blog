# 关于页版式统一设计

## 目标

让“关于”页与分类、标签、归档、专题等一级 Tab 页面保持一致，去掉右侧独立作者卡造成的文章详情页观感，同时保留必要的作者身份与 GitHub 入口。

## 页面结构

页面使用现有一级 Tab 的标准结构：

1. 外层使用单列 `wrap`。
2. 顶部使用共用 `page-head`，展示 `ABOUT`、标题“关于知行”和简短说明。
3. 下方使用一个全宽 `panel` 承载现有“关于知行”正文。
4. 作者头像、姓名、简介和 GitHub 入口移到正文底部，展示为简洁的横向作者栏。

## 视觉原则

- 删除现有 `listing-grid` 与右侧 `aside`，不保留双栏布局。
- 正文继续使用现有 `prose` 排版，保留“写作原则”和“技术栈”内容。
- 底部作者栏不使用独立浮动卡片，不与正文面板形成卡片嵌套。
- 作者栏使用分隔线与正文区分；头像、文本和 GitHub 按钮横向排列，移动端允许自然换行。
- 页宽、页头间距、边框和圆角沿用其他一级 Tab 页面，不引入新的颜色体系。

## 范围

- 修改 `src/pages/about.astro` 的结构。
- 在 `src/styles/global.css` 增加关于页作者栏样式并补充移动端规则。
- 不修改关于页现有正文文案，不影响其他页面的作者卡、侧栏或 `AuthorAvatar` 组件。

## 验收标准

- 关于页只有一个全宽主体面板，没有右侧卡片。
- 页头结构与其他一级 Tab 页面一致。
- 作者信息位于正文底部，GitHub 入口可访问。
- 桌面和移动端无横向溢出、文字遮挡或布局跳动。
