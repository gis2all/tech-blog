# 专题总览页重设计

## 目标

将 `/series/` 从简单文字列表升级为与项目页一致的图文卡片总览，并把现有文章整理成五条清晰、可连续阅读的实践路径。

## 范围

- 仅重设计专题总览页 `/series/`。
- 保持专题详情页 `/series/[slug]/` 的文章列表不变。
- 保持首页和正文页左侧专题筛选行为不变。
- 删除空的 `AI Agent 工程化` 专题。

## 内容结构

专题固定为五个，按以下顺序展示：

1. Google Earth Studio 从入门到进阶，4 篇。
2. Appium Android 自动化测试实战，6 篇。
3. .NET Core 测试与代码质量，7 篇。
4. Jenkins Pipeline 工程实践，12 篇。
5. Jenkins 节点与运维排障，10 篇。

每篇入选文章通过 frontmatter 的 `series` 和 `seriesOrder` 建立专题归属与阅读顺序。专题采用精选路径，不收录所有仅有弱关联的文章。

## 卡片设计

- 页头说明为“按主题整理的系列文章与实践路径。”
- 卡片使用文章正文中的真实截图作为封面，裁切为 16:9。
- 卡片包含封面、标题、说明、文章数量与“查看专题”入口。
- 封面、标题、入口均链接到专题详情页。
- 桌面端三列，五张卡片形成 3 + 2；移动端单列。

## 数据结构

专题 JSON 在现有字段上增加必填的 `image` 和 `imageAlt`。封面统一生成到 `public/images/series/`，避免专题页直接依赖文章内部图片路径。
