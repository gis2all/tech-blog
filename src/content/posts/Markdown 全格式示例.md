## 列表

无序列表（含嵌套）：

- 第一项
- 第二项
  - 嵌套项 A
  - 嵌套项 B
- 第三项

1. 第一步
2. 第二步
   1. 子步骤一
   2. 子步骤二
3. 第三步

## 代码

行内代码：`const answer = 42;`

代码块：

```js
function greet(name) {
  // 测试超长行是否横向滚动，而不撑破页面布局
  return `Hello, ${name}! 这是一段较长的说明文字，用来验证代码块在超出行宽时的横向滚动表现。`;
}

console.log(greet("知行"));
```
